# Navin Manohar — Portfolio

AI Engineer & Backend Developer portfolio built with Next.js 16, React 19, TypeScript, Tailwind CSS v4, Framer Motion, and shadcn/ui.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **UI Library**: React 19
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Components**: shadcn/ui (Base UI Nova)
- **Icons**: Lucide React

## Sections

- Hero — Animated floating tech cards with role and tagline
- About — Engineering mindset with impact-driven highlights
- What I Build — AI/LLM Systems, Backend Architecture, Full Stack Products
- Featured Projects — 6 project cards with metrics, features, and tech stacks
- Experience — Vertical timeline with AppVin Technologies & GeeksforGeeks
- Education — B.Tech, Diploma, and certifications
- Tech Stack — Categorized badges across AI/LLM, ML/NLP, Backend, Databases, DevOps
- GitHub — Repo cards with contribution graph
- Contact — Email, GitHub, LinkedIn links

## Features

- Dark/light mode toggle with localStorage persistence
- Fully responsive, mobile-first
- Smooth scroll navigation with active section tracking
- Framer Motion fade-in, hover, and reveal animations
- SEO optimized with Open Graph metadata
- Resume PDF download

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm run lint
```
